# MarkDown 简单介绍

> Markdown 是一种可以使用普通文本编辑器编写的标记语言，通过简单的标记语法，它可以使普通文本内容具有一定的格式。——百度百科

```
Markdown语法简单，功能强大，因此广泛应用于写博客。Markdown的转化十分多样，在网上就能找到在线转化工具，https://tableconvert.com/，转化为多种形式，十分便利。
    以及用Markdown记笔记时，不怎么需要动鼠标，只需要敲几下键盘，就能满足需求。
```

# MarkDown语法

### 标题

```
# 标题1
## 标题2
### 标题3
#### 标题4
##### 标题5
###### 标题6
等同于 HTML 语言中的 h1 ~ h6
```

## 标题2

### 标题3

###### 标题6

### 列表

Markdown中只需要在一行文字前加上符号'\*'或'-'即可变为无序列表,有序列表则加数字。

```
无序列表
* 1
* 2
* 3

有序列表
1. 1
2. 3
3. 3
```

**(注意空格)**

### 引用

如果需要引用一段句子，可以在文本前加入'>',即大于号

```
> 这样引用
```

> 这样引用

### 链接

```
格式为[文字](url)
```

示例：
文字填百度，url填'https://www.baidu.com/'
[百度](https://www.baidu.com/)

### 图片

与链接用法一致，只不过前面加上感叹号'!'

```
格式为![]()
```

### 粗体与斜体

Markdown中用两个 _包含一段文本就是粗体的语法，用一个_ 包含一段文本就是斜体的语法。

```
例如：**这里是粗体** *这里是斜体*
```

例如：**这里是粗体** _这里是斜体_

### 表格

表格语法比较麻烦,举个例子：

```
| 列1 | 列2 | 列3  |
|----|----|-----|
| a  | aa | aaa |
| b  | bb | bbb |
| c  | cc | ccc |
```

| 列1 | 列2 | 列3 |
| --- | --- | --- |
| a   | aa  | aaa |
| b   | bb  | bbb |
| c   | cc  | ccc |
